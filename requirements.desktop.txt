# Live2D Master Agent — 桌面安装包内置运行时依赖清单
# ---------------------------------------------------------------------------
# 用途：scripts/build_desktop_bundle.py 用它装配「随安装包分发」的嵌入式 Python
# 运行时。目标 = 用户装完即可用，无需自己装 Python 或任何依赖。
#
# 装配方式（在 Windows 构建机上执行）：
#   python -m pip download --only-binary=:all: -d <wheels> -r requirements.desktop.txt
#   python -m pip install --no-index --find-links <wheels> --target <bundle>/python/Lib/site-packages -r requirements.desktop.txt
#
# 全部钉 CPU 版：
#   - Windows 上 PyPI 默认 torch 即 CPU wheel（不含 CUDA），对没有 N 卡的机器
#     同样可用；CUDA 版体积巨大且只有 N 卡用户受益，故不内置。
#   - 目标 Python = 3.12（embeddable 3.12.10），要求各包存在 cp312 / abi3 / py3
#     的 win_amd64 轮子（已逐一核验）。
#
# 版本下限与仓库 requirements.txt 对齐（CI 已验证可安装），避免越级抬升带来
# 无 cp312 轮子的风险；live2d-py 按 ADR-007 钉死 0.8.1（1.0.0 移除 live2d.v3，
# 与验收链不兼容）。
#
# 下限抬升与 CVE 的对应关系见 requirements.txt 同名注释（逐条经 OSV.dev 核实，
# 2026-10-23）。Pillow 13.0.0 / rembg 2.0.86 / scikit-learn 1.9 均要求
# Python>=3.11 —— 与本清单的目标 Python 3.12 相容。
#
# 版本号单一真源见 core/version.py。

# ===== AI：SAM2 语义分割 —— 刻意**不**内置（由应用内按需下载） =====
#
# torch / torchvision / transformers / segment-anything / huggingface-hub 这一组
# **不随安装包分发**。三条证据都指向「不该打包」：
#
# 1) 设计契约本来就不含它们：core/capabilities.py 的模块文档写着
#    「基础包（requirements.desktop.txt）只带零前提主链路所需的轻依赖；
#      SAM2/torch、rembg、mediapipe、ASR、TTS、diffusers 等重能力不进包，
#      由应用内按需下载器落 site-packages / 用户缓存」；
#    api/services/capability_manager.go 的 capabilityPlans 也已接线
#    sam2_gd 组的一键安装。此前清单把整组打进安装包，与自己的设计文档直接矛盾。
#
# 2) 装了也用不上：Segmenter 的 auto 后端要「HAS_TORCH **且**找到 SAM 权重」
#    才选 sam（core/segment_engine/semantic.py::_resolve_backend），而装配脚本
#    只内置 ISNet 权重（models/rembg/isnet-anime.onnx），桌面端的 auto 恒走
#    isnet。torch 在默认链路上完全不参与。
#
# 3) 体积代价大：torch 的 win_amd64 wheel 约 119MB（PyPI 实测），解压进
#    site-packages 约 400–500MB —— 占 1.4GB 安装包的三分之一左右，
#    却换不来任何默认功能。
#
# 需要 SAM2 时：应用内点「下载」即可（Go 侧 capabilityPlans 实测可装），
# 或手动 pip install。版本下限仍以 requirements.txt 为准：
#   torch>=2.14.1（2.0.0 命中 28 条 CVE，2.13.0 起修复）
#   transformers>=5.17.0（sam2_gd.py 按 5.17.0 验证；4.x 没有 Sam2Model 等类）
