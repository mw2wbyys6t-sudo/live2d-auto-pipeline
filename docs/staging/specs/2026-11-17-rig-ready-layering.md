# 高质量 Rig-ready 分层与 PSD 结构

date: 2026-11-17
milestone: M1-M3（见 docs/ROADMAP.md）
status: 已批准（2026-11-17）；M1 离线验收完成，未验证项见计划验证记录

## 目标

将当前自动分层从“语义 PNG 切片 + 52 层名称映射”提升为可审计、可编辑、可导入 Cubism 建模的 Rig-ready PSD 与配套 Live2D 图层资源。以 `F:\DeepSeek免费公皮\psd\大肥鱼公皮分享拆分.psd` 的组织和部件独立度作为质量参照，不复制其原画、角色专属外观或所有 418 个可见叶子层。

## 范围

in_scope:
- P0 基础结构：胸腔/躯干、腰臀、左右一致的上臂/前臂/手、大腿/小腿/脚；服装内外层及可靠的左右语义。
- P1 动画关键部件：后发分束、侧发与前发束；左右眼眼白、虹膜/瞳孔、高光、上下睫毛、眼睑、左右眉；口腔、上下唇、牙齿、舌头（只在输入像素证据充分时拆出）。
- P2 可选素材：从输入 PSD/已有素材继承表情、动作手势、服装变体；普通单张立绘不凭空生成未画出的手势或服装内容。
- 从源 PSD 保留组层、组可见性、图层顺序、画布坐标、图层名、透明度和可复核来源；自动分层结果提供语义组与顺序，不得伪称恢复了不存在的原始图层信息。
- 对深度与遮挡单独建模：显式近/远侧与前/后关系、被遮挡区域补全来源、可信度及复核状态；不得以单纯 draw order 推断真实深度。

out_of_scope:
- 不以参考 PSD 的总叶子层数作为硬目标。
- 不自动制作参考 PSD 中不存在于当前源图的专属配件、表情、动作或服装变体。
- 不在本规格阶段直接修改生产代码、生成/覆盖当前模型产物、操作 VTube Studio、发布或上传素材。

## 决定

approaches:
- A. 扩充 52 层标签映射并用现有几何规则直接填槽。优点是改动小；缺点是会把 `leg` 猜成大腿/小腿、把局部 `waistband` 猜成腰臀，并把未知深度误报为完成。拒绝作为主方案。
- B. 建立统一部件契约、来源与置信度账本，按 P0/P1/P2 分阶段生成；可信派生通过测试，不可信部件显式人工复核。优点是可追溯、能阻止错误 ready，便于分阶段回滚；代价是首阶段需要先理清现有命名、mapping、PSD 和导出之间的契约。推荐。
- C. 要求用户逐部件标注/确认所有输入，再生成 PSD。优点是语义风险最低；缺点是无法满足自动化批处理和无需人工参与的目标。仅作为低置信度 fallback。

contract:
- 每次分层产物包含 `layers/`、可导入的分组 PSD、机器可读 manifest、可视化分层检查报告和来源图标识；manifest 对每层记录稳定 ID、语义部件、左右侧、父组、draw order、画布原点/尺寸、来源 mask、深度关系、遮挡补全方式、confidence、合成/推断标记和质量状态。P0 必须交付 PSD；若 writer 无法保真支持输入结构，则该阶段失败并保留 PNG/manifest 诊断产物，不静默降级成 PSD。
- 部件状态采用 `detected`、`derived`、`completed`、`manual_required`、`missing` 等明确状态；只有证据支持且通过质量闸门的图层才可标为 `ready_for_rigging`。
- readiness 分为 `exportable`、`rig_ready` 与 `quality_ready`：受限推断层允许进入导出候选，但其 `derived` provenance/confidence/依据必须可见；证据缺失或低置信度不得标为 `quality_ready`。`manual_required` 的必需部件会阻断 `rig_ready`；导出候选成功不能被描述为高质量通过。
- 输入 PSD 的图层结构是权威来源：保留原组/图层关系和各状态。输入为单张 PNG 时生成新语义组，并将推断层与合成层明确标记，禁止声称其为原始画稿层。
- P0/P1/P2 分阶段交付；每阶段独立冻结产物和报告，阶段未通过不得进入下阶段绑定导出。

invariant:
- INV-1 语义真实性：不得把 `waistband` 等局部服装件映射成 `Waist_Hips` 等不同身体语义；标准槽位状态必须能追溯到真实检测、受限派生或人工确认。
- INV-2 左右一致性：适用部件按角色自身坐标约定输出 L/R；同一肢体层级的对应侧必须齐全，缺侧明确失败，不得静默把整块 mask 伪装成左右双层。
- INV-3 拆分守恒：纯分区派生层之间无意外重叠且并集等于源 mask；有意重叠/遮挡补全必须声明其角色和来源。静止复合比较用于发现覆盖缺口，不要求推断/补全像素与源图一致。
- INV-4 深度可信：近远关系必须来自可解释的证据（输入层次、局部前后顺序、受约束的几何/视觉证据或人工确认）；证据不足时标 `manual_required`，不能自动编造。
- INV-5 可变形完整性：需独立活动的部件在安全动作范围内不得露透明洞、越界补全块、错侧绑定或纹理错位；安全范围由离线变形压力测试定义。
- INV-6 表情/动作真实性：只从输入 PSD 的替代图层或明确授权的内容生成表情和动作素材；不得将单帧普通分割结果当作已具备替代口型/手势的内容。
- INV-7 可信报告：检测、映射、质量和 PSD 写出层数/顺序一致；任何降级、未映射、缺件或 PSD 导出失败都必须使相应阶段非 ready。

quality_gates:
- P0 可绑定基础：左右四肢对称槽位齐全或明确标缺；胸/躯干、颈、腰臀、衣物内外结构语义正确；深度/遮挡报告完整；必需图层无错侧、空层、无来源推断或伪映射。
- P1 动画部件：发束、眼部和口部细分只在独立结构得到证据支持时通过；各层关系、透明边界、draw order 与绑定槽位可审计。
- P2 扩展素材：输入确实包含的表情、动作和服装变体按组保留并可切换；不适用项目标记 N/A，不算缺失，也不合成假内容。
- 所有阶段均做 PSD 重新读取验证、画布/原点验证、图层顺序验证、alpha 支持域/叠放关系验证、质量报告与导出 loader 一致性验证。
- 离线 deformation stress 对脸转向、眨眼、口型、抬臂/肘、腿部/裙摆、头发摆动分别测安全范围；安全范围内空洞率为 0，超范围输出风险而非声称通过。

test:
- 基于真实参考 PSD 建立不包含像素内容的结构 fixture：组路径、层名语义、左右部件、可见状态、层序和坐标信息；保留作者署名与禁止重新分发约束。
- P0 合成 fixture 覆盖双侧齐全/缺侧、肢体单块/左右分离、胸躯干相连/遮挡、服装与身体重叠、深度未知等边界。
- P1 fixture 覆盖左右眼细分、低分辨率/无瞳孔高光、发束连通与不可安全分割、嘴部仅闭口线等不应臆造的情形。
- P2 fixture 覆盖多状态 PSD 组、不可见组、替代服装、手势和表情层的原序/坐标保留，以及 PNG 输入不伪造变体。
- 每个阶段均验证：PSD 可重读、manifest 与 PNG/PSD 层一一对应、未映射无伪 ready、必要遮挡来源存在、静止复合与压力测试报告可重复。

failure_modes:
- 关键部件检测/拆分置信度不足：保留可追溯原层，标 `manual_required`，该阶段不通过；不得按名称猜测补齐。
- 左右侧推断方向不确定或人体中线质量不足：不拆或标人工复核，不以画布中心作为无条件正确答案。
- amodal completion 无可信可见上下文或补全面积异常：不生成补全图层；保留原始 mask 并报告缺口。
- PSD writer 不支持的混合模式、剪贴、蒙版或智能对象：保留可编辑导入源并明确报告未保真的结构；不得静默扁平化后宣称完整等价。
- 当前 52 层 schema 与真实语义不一致：修订 schema/映射契约；禁止仅为提高 mapped 数量而错误对齐名称。

## 实施阶段

1. P0：层语义契约、来源证据/manifest、左右对称四肢、胸腔/躯干与衣物内外层；先修正错误映射和阶段 ready 闸门。
2. P1：发束、眼部和口部细化；引入受限分拆策略和不能拆时的明确状态。
3. P2：输入 PSD 的表情、手势、备用服装组保留与可切换导出；单张图输入只提供已有内容。
4. 全链路：可导入 PSD、模型层加载、离线 Rigging/mesh/texture 导出、MOC3 校验、离线形变压力测试和质量报告对账。

## 决策状态

- status: 已批准（2026-11-17）
- responsibility: 用户 + 本地自动化测试；每阶段由独立审查检查验收证据，负责人须在实施计划中指定。
- decision: 采用方案 B；方案 C 只用于低置信度部件的人工确认 fallback。
- reversibility: 两向门。manifest 和 semantic slot contract 可按版本迁移；PSD 分组/命名一旦用于用户 Cubism 编辑项目，变更成本高，需版本化 schema 并保留旧清单读取兼容。
- reconsider_if: 真实素材证据显示某标准部件无稳定像素/深度依据，或离线压力测试证明当前层级无法满足可动作需求；届时将槽位降为 optional/manual 而不是生成合成假部件。

## Working notes

- 已观察的参考 PSD：3749×7697；`身体` 可见树有 418 个叶子图层，包含身体、后发、手、袖子、裙装、五官、前发等分组，也存在未拆备份、不可见备用服装、表情和动作组。总叶子数不是基础目标。
- 当前 `sam2gd_run5`：35 个 layer guide 输出；52 层指南映射 15/52；层指南将 `waistband` 映射到 `Waist_Hips`，语义可能错误；当前仅 `hair_back`、`neck`、`clothes_top` 标记 amodal completed；右上臂缺失。
- 当前代码把 `split_limb_parts`、`split_garment_details`、`refine_part_masks` 与 `AMODAL_PARTS` 分别维护；这些关系必须进入单一可验证的部件契约，否则 mapping 表不能作为自动-ready 的权威证据。
- 参考 PSD 使用规范禁止重新分发原始 PSD。测试/报告只记录结构元数据，不复制或提交参考 PSD、纹理或可恢复的图像内容；任何外部上传前须征询用户。
- 尚未确认：模型最终交付必须直接生成分组 PSD，还是先提供经过验证的分组 PNG + manifest 供 Cubism 导入。优先在设计确认时决策；默认建议将可导入 PSD 列为 P0 交付，但要求对不支持结构显式失败。
