# M2：P1 部件证据闭环与形变压力验收

date: 2026-11-19
milestone: M2（见 docs/ROADMAP.md；父规格 2026-11-17-rig-ready-layering.md）
status: 已批准（用户选择「A 先 B 后」）

## 目标

补齐 M2 的**证据与验收**缺口（A），再补 P1 部件的**真实细拆**（B）。A 不改分割算法，
只让已有的降级事实可见、让补全可信度可核对、让形变安全范围可度量。

## 范围

in_scope_A:
- 拆分降级原因（未按中线拆、缺侧、眼白/虹膜明暗差不足、前后发拆分失败、深度差不足）
  从「只写日志」变为写入 manifest，并区分 informational 与 degradation。
- amodal 补全记录 `completion_method` 与 `completion_confidence`，低置信度不得宣称高质量。
- 6 类动作（脸转向 / 眨眼 / 口型 / 抬臂肘 / 腿部裙摆 / 头发摆动）的离线形变压力测试，
  度量轮廓内空洞率，给出安全范围。

in_scope_B:
- 眼部细拆：在既有 eye 掩码内按证据拆瞳孔 / 高光 / 上下睫毛；证据不足保留整块并标 manual_required。
- 口部细拆：在既有 mouth 掩码内按证据拆牙齿 / 舌头 / 上下唇；仅闭口线时保留并标 manual_required。

out_of_scope:
- 不修改现有 split 阈值、不改变已通过测试的拆分结果像素。
- 不引入新的学习式模型或外部权重。
- 不改变 PSD writer / moc3 导出契约。

## 决定

contract:
- `part_split.py` 的警告保持 `List[str]` 语义不变；新增 `SplitNote(str)` 子类携带
  `code`（机器码）与 `part`（受影响部件名）。现有 `"xxx" in msg` / `not warnings`
  断言与日志输出不受影响。
- degradation 机器码集合固定：`limb_no_midline`、`limb_single_side`、
  `eye_low_contrast`、`eye_ratio_abnormal`、`hair_front_back_failed`、
  `depth_insufficient`、`depth_ratio_unbalanced`。其余为 informational。
- `LayerComposer.compose()` 返回的每层 dict 增加 `split_warnings: List[str]` 与
  `split_limited: bool`；`compose()` 仍返回 `Dict[str, Dict]`，不破坏 12+ 处调用方。
- `LayerEntry` 增加 `split_warnings`、`split_limited`、`completion_method`、
  `completion_confidence`，并全部写入 `to_dict()`。
- 补全方法枚举：`pix2gestalt` / `diffusion` / `telea` / `simple_fill`；对应基线置信度
  0.90 / 0.40 / 0.60 / 0.30（可解释、单调，按方法而非像素内容打分）。

invariant:
- INV-A1 拆分降级可追溯：任一 degradation 码都必须能在 manifest 对应层的
  `split_warnings` 里找到原文，且该层 `split_limited=true`。
- INV-A2 降级不得伪高质量：存在 `split_limited` 层的清单，`quality_ready=false`；
  但 `rig_ready` 判定不变（避免把既有可导出结果拦死，见父规格「exportable vs quality_ready」）。
- INV-A3 补全可信度可见：`status=completed` 的层必须有 `completion_method` 与
  `completion_confidence`；缺失即为契约违规（写入 manifest warning，`quality_ready=false`）。
- INV-A4 形变安全：声明的安全范围内，6 类动作变形后轮廓内空洞面积必须为 0；
  超出安全范围只输出风险，不宣称通过。

test:
- `tests/unit/test_split_notes.py`：SplitNote 仍是 str；degradation 码覆盖；
  现有 `not warnings` 场景不新增警告。
- `tests/unit/test_layer_manifest.py` 追加：degradation 进入 manifest、`split_limited`
  阻断 `quality_ready` 但不改 `rig_ready`、completed 层缺 confidence 时告警。
- `tests/unit/test_deform_stress_gate.py`：6 类动作各自在安全范围内空洞面积为 0，
  且超范围时 gate 报风险而不通过。
- 全量 `pytest tests/unit` 无回归。

failure_modes:
- 某部件既无检测层也无派生层：不新增合成假层，保持缺失状态。
- 形变 raster 因 OpenCV/PIL 缺失无法完成：`available=false`，判据一律 null（未验证），
  不得洗成通过。
- 补全方法无法识别（例如未来新增）：`completion_method="unknown"` 且置信度 0.0，
  阻断 quality_ready。

deferred:
- 多目标侧摆链（`_inner` / `_outer` 双束绑定）。
- 逐发绺（lock-level）细分。
- 真实 GPU/内核形变渲染级验收（本阶段只用 CPU raster 的轮廓空洞率）。

## Working notes

- 现状：`part_split.py` 15 处 `warnings.append` 全部只经 `composer.py:385-387` 写日志；
  `semantic.py` 与 `workflow.py` 拿不到，manifest 无字段。
- `split_hair_bangs_strands`（1044-1053）与 `_split_at_midheight` 失败分支**静默保留**，
  属「不拆是正确行为」，不新增警告（否则打破 `not warnings` 断言）。
