# 工作台 UI 重设计（v0.11）

> 范围：视觉层 + 信息架构；保留「单页三栏 + 顶部四阶段」结构。功能、接口、无障碍语义不变。

## 1. 设计目标

1. **角色优先**：画布是舞台，UI 是舞台边框。把高饱和色只留给"当前角色 / 当前动作"，大面积保持低明度紫黑，避免长时间使用疲劳。
2. **一次看懂进度**：顶部四阶段必须回答"我在哪一步 / 哪几步已有产物 / 当前在跑什么"。
3. **二次元质感但不幼稚**：樱花粉 + 鸢尾紫的点缀色、发光描边、圆角卡片、宝石状步骤徽标；不使用插画/贴纸干扰操作区。
4. **工具感**：12px 正文、等宽数字、紧凑行高，所有面板可独立滚动，画布永不被挤压。

## 2. 色彩令牌

统一走 Tailwind 颜色别名（`ink / sakura / iris / mint / haze`），组件里不再出现散落的 `#xxxxxx`。

| 语义 | 令牌 | 值 | 用途 |
| --- | --- | --- | --- |
| 画布底 | `ink-950` | `#08060f` | 应用最底层 |
| 应用底 | `ink-900` | `#0b0814` | 顶栏 / 主区 |
| 作品栏 | `ink-850` | `#100c1b` | 左栏 |
| 操作台 | `ink-800` | `#151022` | 右栏 |
| 卡片 | `ink-750` | `#1b1529` | 列表项 / 信息块 |
| 悬停 | `ink-700` | `#231b34` | hover 底色 |
| 描边 | `ink-650` | `#2b2240` | 分隔线 |
| 主强调 | `sakura-500` | `#ff5c9d` | 主按钮、当前阶段、焦点 |
| 次强调 | `iris-500` | `#8b5cf6` | 渐变尾色、动作/参数 |
| 信息 | `mint-400` | `#34e0c4` | 完成、在线、可绑定 |
| 警告 | `amber-400` | `#fbbf24` | 占位图、缺前置产物 |
| 危险 | `rose-400` | `#fb7185` | 失败、停止 |

渐变：
- 主行动：`linear-gradient(135deg, #ff5c9d, #8b5cf6)`
- 当前阶段描边：`linear-gradient(135deg, rgba(255,92,157,.9), rgba(139,92,246,.9))`（1px hairline）
- 背景极光：两团 30% 透明度的粉/紫径向光，`position: fixed`，不参与布局。

## 3. 字体与排版

- 中文栈保持 `PingFang SC / Microsoft YaHei / Noto Sans SC`，不引入外部字体。
- 字号只有 4 档：`10px` 辅助、`11px` 说明、`12px` 正文、`14px` 区块标题；品牌名 `15px`。
- 数字一律 `tabular-nums`；参数名用 `font-mono`。
- 行高：正文 1.6，标题 1.3；面板内段落最大宽度不限制（面板本身窄）。

## 4. 形状与层次

- 圆角：应用壳 `0`；面板 `18px`（`rounded-2xl`）；卡片 `14px`（`rounded-xl`）；按钮/输入 `10px`；标签 `999px`。
- 描边：`1px rgba(255,255,255,.07)`；当前项换成 1px 渐变 hairline + 外发光。
- 阴影：`shadow-panel`（大而淡，分离三栏）、`shadow-glow-sakura`（当前项）。
- 层级：底 → 面板 → 卡片 → 浮层（抽屉/提示）；画布内浮层用 `bg-ink-950/70 backdrop-blur`。

## 5. 信息架构

### 启动页（`/`）
- 独立全屏页，不出现三栏：品牌 + 主行动 + 最近作品，作为应用打开后的第一屏。
- 主行动「继续上次作品」→ `/studio`（恢复上次作品与阶段）；「新建角色」→ `/studio?new=1`；最近作品卡片 → `/studio?work=…`。
- 工作台本体迁到 `/studio`；旧入口 `/generate`、`/layers`、`/preview`、`/export` 重定向到 `/studio?stage=…`。

### 桌面开机页（Tauri）
- 代码在 `desktop/launch/`（Vue 3 + Vite），构建为单文件 `desktop/dist/index.html`，由 Tauri 直接加载。
- 顺序：应用图标先出现并旋转 360° → 唯一文案「Pygmalion Studio」淡入 → 后端就绪后淡出，直接进入 `/studio`。
- 正常启动画面不显示进度、版本、步骤或状态文字；失败时只出现一个无文字的刷新按钮。
- 图标直接使用 `desktop/icons/128x128@2x.png`，更换应用图标即同步更新开机页。

### 工作台（`/studio`）
保持单页三栏，只做"压缩与分组"：

```
┌ 顶栏 56px：品牌 + 当前作品 + 连接状态 / 刷新 / 新建 / 自检 ─────────────┐
├ 阶段轨道 52px：① 生成 ─ ② 分层 ─ ③ 预览 ─ ④ 导出（含产物就绪勾）──────┤
│ 作品栏 260px │ 画布（StageHeader + 舞台框）        │ 操作台 372px        │
│ 列表/新建     │ 四个阶段共用 StageHeader            │ 4 个 Tab 分段控件    │
│ 空态插画文案  │ 画布区圆角 18px + 点阵 + 内发光      │ 内容独立滚动        │
└ 底部状态：作品数 / 版本 ─────────────────────────────────────────────┘
```

- 顶栏高度从 56 固定，阶段轨道常驻；窄屏（<1280px）作品栏改为抽屉，画布保底宽度。
- 阶段切换只切换画布内容与右栏默认 Tab，三个区域各自滚动，不整页滚动。
- 每个阶段页统一：左标题 + 一句解释，右侧该阶段的主动作；主体是画布/列表；底部是元信息条。

## 6. 组件规范

### 阶段轨道
- 四个等距步骤，之间有 1px 轨道线；已就绪步骤用 `mint` 勾，当前步骤用粉紫渐变徽标 + 发光 + 底部渐变指示条。
- 运行中在轨道下方追加一条 2px 渐变进度条 + 当前步骤文案 + 百分比。

### 作品栏
- 卡片：`48×60` 竖版缩略图（无图时渐变占位 + 图标），两行文本（提示词截断 / 时间），底部状态 chip（分层 / 模型 / 占位图）。
- 当前卡片：渐变 hairline + `shadow-glow-sakura` + 左侧 2px 竖条。

### 操作台
- Tab 改为分段控件（segmented），激活项为 `ink-750` 胶囊 + 粉色文字；右侧显示图层数徽标。
- 每个 Panel 由若干 `section` 组成，区块标题统一 `text-[11px] text-haze-400`，区块间 `space-y-5`。
- 输入控件统一 `.field`：深底、1px 描边、聚焦粉色描边 + 1px 外发光。
- 主行动按钮统一 `.btn-primary`；次行动 `.btn-ghost`；危险 `.btn-danger`。

### 画布
- `.stage-frame`：`rounded-2xl` + 1px 描边 + 内阴影 + 24px 点阵 + 顶部 1px 高光。
- 空态：宝石形图标底座 + 标题 + 一句可执行指引 + 一个主按钮。

## 7. 动效

- 入场：`fade + translateY(4px)`，180ms `ease-out`；阶段切换重放。
- 当前项发光用静态阴影，不做呼吸动画（避免长时间闪烁）。
- 进度条使用渐变 + 500ms 宽度过渡；尊重 `prefers-reduced-motion`。

## 8. 落地顺序

1. `tailwind.config.js` + `styles/globals.css` 令牌与组件类。
2. 外壳：`Workbench` → `StageBar` → `WorkpieceRail` → `Inspector`。
3. 阶段页：`Generate/Layers/Preview/Export` + 新增共用 `StageHeader`。
4. 面板：`Prompt/Layers/Params/Export` + `ParameterSlider`、`ConnectionStatus`。
5. `npx tsc --noEmit` → 静态导出 → 覆盖 `api/webui/dist` → 8080 浏览器验收。
6. 验收通过后再进入链路优化（分层质量、compatibility 矛盾、Parts 悬空引用）。
