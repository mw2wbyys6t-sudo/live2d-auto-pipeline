# 参照物先行的 Live2D 三轨重建 — 设计规格

- 日期：2026-11-04
- 状态：待用户审阅
- 目标：从单张立绘全自动生成可复杂运动、形象稳定、具有自然物理响应的原生 Live2D 模型
- 路线：参照物先行，G（几何）/ S（生成）/ M（运动）三轨解耦

## 1. 背景与根因判断

当前管线已经能够完成图片分层、网格与参数生成、moc3 导出以及运行时预览，也已修复头、眼球和淡入层未共享躯干侧倾键形带等确定性装配缺陷。这些修复必须保留，但它们不能单独把现有产物提升为商业 Live2D 成品的自然运动。

对用户提供的 DeepSeek 免费公皮进行只读研究后，根因判断为：

1. **几何资产太薄。** 当前分层倾向于只保留可见区域和少量扩边，无法在部件相对运动时持续覆盖接缝。
2. **变形结构太浅。** 共享一个旋转场只能解决部分同向运动问题，不能表达头颈、头发、服装和四肢的层级体积变化。
3. **物理响应过于同步。** 全层共用相似曲线只能产生“脚本移动感”，不能产生主干保持、部件延迟、衰减和回摆并存的自然感。
4. **补画与运动相互脱节。** 没有遮挡余量的层不应获得大幅运动；补画不足时必须限制运动，而不是导出后露底。

因此，后续主线不再是逐个修补接缝或增加图层数量，而是重建“完整部件几何 → 可信遮挡补画 → 原生层级运动”的端到端链路。

## 2. 已确认的产品约束与决策

| 编号 | 决策 |
| --- | --- |
| D1 | 坚持全自动：一张图生成模型，不要求手工分层源图或强制人工修图 |
| D2 | 允许使用生成模型补画遮挡区域，大块 amodal completion 是核心能力 |
| D3 | 自建风格模型，不停留在付费 API 或插件接口；通过统一接口逐步替换底层能力 |
| D4 | 数据来自许可允许的网络素材或自生成图片，训练前逐样本核许可 |
| D5 | 以 DeepSeek 公皮作为视觉、结构与运动参照物，但不机械复制其资产数量 |
| D6 | 采用 G / S / M 三轨解耦，先固定验收口径，再分阶段实施 |
| D7 | Python 负责离线构建；逐帧运动由原生 moc3 键形、变形器和物理系统求值 |
| D8 | 参考素材只用于研究和验收，不默认进入产品、训练集或发布包 |

## 3. 参照物实测依据

### 3.1 结构与运行时行为

研究时采样的结构对照如下。数量用于说明能力差距，不作为自动产物的数量目标。

| 指标 | DeepSeek 参考 | 研究时 singer_follow |
| --- | ---: | ---: |
| 参数 | 509 | 28 |
| Parts | 147 | 33 |
| ArtMeshes | 715 | 33 |
| 顶点 | 58,967 | 6,604 |
| Deformers | 822 | 12 |
| Warp / Rotation | 723 / 99 | 12 / 0 |
| 变形器深度中位数 / 最大 | 13 / 22 | 0 / 0 |
| 带遮罩网格 | 182 | 0 |
| Glue | 38 | 0 |
| 物理组 | 131 | 5 |
| 纹理 | 5 张图集 | 34 张单层纹理 |

其他实测事实：

- 参考模型 90 个参数具有实际 keyform binding，存在 62 个多轴 band，最多 4 轴。
- 91/131 物理组是多输入；19 个物理输出又作为其他物理输入，形成真实级联。
- `Part15 脸` 只有 5 个网格，却有 72 个变形器，说明自然运动主要来自层级变形而非单纯增加网格。
- VTube 映射对头角和身体位置使用不同平滑参数；`ParamBreath` 是外部自动输入，不是模型内部永久运行的一条 Python 正弦脚本。
- 头角和身体位置是持久响应；前发、后发和裙摆具有逐级错开的峰值，并在持续输入下表现出衰减、过零和回摆。

### 3.2 PSD 遮挡与合成

参考 PSD 的实测结果：

- 118 个组、636 个叶子层；有效可见 418 叶，缩尺后非空 373 叶。
- 逐层面积冗余为 74.19%；137 层完全被覆盖，201 层部分覆盖。
- 尾巴图层 `图层 136` 的 60,677 个缩尺像素中有 55,119 个被上层覆盖，占 90.84%，仍保留完整绘制内容。
- 长裙图层 `图层 76` 有 52.51% 被覆盖，同样不是窄边扩线。
- 92.89% 的层对仍为零重叠，说明重叠验收只能针对真实遮挡层对，不能要求全局两两重叠。
- 朴素 normal source-over 重合成与参考合成在内容区的 RGB MAE 为 32.07/255，证明剪贴、组蒙版和非 normal blending 不能丢失。
- 560/636 个叶名是通用编号，自动识别必须利用组路径和几何，不能依赖叶层名称。

研究产物保存在仓库外的本机临时目录（如 `reference_moc3_report.json`、`reference_physics_metrics.json`、`reference_part_map.json`、`psd_gold_analysis/report.json`）。这些文件是研究证据，不是产品运行时依赖，也不随仓库分发。

## 4. 目标与非目标

### 4.1 目标

1. 单张立绘自动生成具有真实遮挡余量的完整部件，而非仅切出可见碎片。
2. 静止重合成忠实于输入，原图可见像素不被生成模型改写。
3. 复杂组合姿态下无成片露底、五官脱离、反向拉扯、明显穿插或体积塌陷。
4. 原生模型支持共享主干变形、部件局部位姿、多输入物理和级联回摆。
5. 补画能力可插拔，自建风格模型可以在不改写 G/M 的情况下替换升级。
6. 所有成功、降级和失败状态均有实测证据，不用参数数量或像素变化量冒充质量。

### 4.2 非目标

- 不要求自动产物达到参考模型的参数、网格、变形器或物理组数量。
- 不把参考 PSD、完整模型或其纹理复制进产品或默认训练集。
- 不在本设计中选定自建风格模型的底座、训练方法或数据规模；这些必须在接口打通后，依据许可和 6GB 显存实测形成独立训练方案。
- 不用全局层对重叠率、网格数或 changed pixels 作为质量总分。
- 不在本设计中增加手工分层或强制人工修图流程。

## 5. 总体架构与数据流

```text
单张立绘
  ↓
G：部件识别、层序、遮挡与剪贴关系
  ↓ 生成补画请求
S：只补遮挡区域，保留全部可见原图
  ↓
G：静止重合成验证 + 完整几何资产
  ↓
M：共享变形场、层级键形、原生物理链
  ↓
moc3 / model3 / physics3 / 纹理与验收报告
  ↓
官方 Core + 产品渲染器 + 连续复杂动作验收
```

三轨职责：

- **G（Geometry）**：决定有哪些部件、谁遮挡谁、需要多少完整几何，以及最终怎样重合成。
- **S（Synthesis）**：只回答被遮住的内容怎样可信地补出来，不决定层序和运动。
- **M（Motion）**：消费几何和遮挡余量，生成原生键形、变形器与物理，不负责重绘角色。

M 发现补画余量不足时，必须能定位到具体层和区域反馈给 G/S；在补齐前限制运动，不得重新生成整张角色或强行放行。

## 6. 共享数据契约

每个部件层至少需要表达以下逻辑信息，具体序列化格式由实施计划复用现有产物结构确定：

| 字段 | 含义 |
| --- | --- |
| `rgba` | 包含可见内容与补画内容的完整层图像 |
| `visible_region` | 原图中直接可见、禁止改写的区域 |
| `generated_region` | S 生成的遮挡补画区域 |
| `occluders` | 覆盖该层的其他部件及其关系 |
| `z_order` | 静止绘制顺序 |
| `clip_mask_blend` | 剪贴、蒙版、透明度和混合语义 |
| `completion_confidence` | 补画可信度及不可信区域 |
| `motion_budget` | 由补画余量和结构可信度允许的运动范围 |
| `provenance` | 输入、模型版本、生成参数与许可追溯信息 |

区域必须能区分“原图可见”“生成补画”“仍不可信”三种状态。只保存一张合成后的 RGBA 会丢失验收和运动降级所需的信息，不足以作为完整契约。

产物能力状态分为：

- `static_ready`：静止重合成合格，但不承诺独立运动。
- `motion_limited`：允许在声明范围内运动，超出范围可能暴露几何不足。
- `complex_motion_ready`：通过完整几何、复杂姿态、物理和运行时验收。

状态必须由对应证据计算，不能由“导出文件存在”直接推导。

## 7. G 轨：自动分层、遮挡补画与静止重合成

### 7.1 部件与关系识别

- 从单张图自动识别头、头发、眼、口、躯干、四肢、服装、前后发等部件。
- 同时建立遮挡、包含、剪贴和绘制顺序关系，不能只输出彼此孤立的层。
- 叶层名称不可靠时，以组路径、位置和几何关系判断，不依赖人工命名。

### 7.2 定向遮挡补画

- 被上层遮住的头发、尾巴、裙片、腿部等，由 S 补出完整轮廓和内部纹理。
- 补画范围由遮挡关系和运动需求决定，不统一扩边，也不把整张图复制到每层。
- 原图可见像素保持不变；生成内容只进入不可见或证据不足的区域，并记录来源与置信度。
- 补画完成后，禁止再按其他层的可见区域清除补画 alpha。

### 7.3 合成语义与输出

- 显式保存 z-order、剪贴、蒙版、透明度和混合模式。
- 眼睛、口腔等内部层保留父级裁切关系，避免运动时溢出。
- 输出完整 RGBA、原始可见区域、生成区域、遮挡者、剪贴关系、允许运动方向和静止重合成图。
- 无法可靠补画的区域必须显式标记，不能伪装成复杂运动可用。

### 7.4 G 轨验收

- 静止重合成与原图进行像素和感知双重比较。
- 对真实遮挡层对检查补画是否形成连续区域，而非只有描边或窄缝。
- 原图可见区域不得被生成模型改写。
- 补画层实际移动后不得出现大面积露底、重复纹理或明显风格跳变。
- 不使用全局两两重叠率作为门槛。

## 8. M 轨：原生 Live2D 变形与分级物理

### 8.1 共享主干变形场

- 从 G 的部件关系建立身体、头、颈、四肢等语义骨架。
- 网格顶点获得连续空间权重；关节附近平滑过渡，眼球、口腔等特殊部件使用独立权重。
- 同一接缝两侧的对应顶点必须受兼容变形场约束，不能给相邻层分别拟合旋转。
- 头跟随身体时，眼球、眼睑和淡入层同步进入对应键形带；转头与身体侧倾可以叠加。

### 8.2 分层变形器图

```text
身体主干
├─ 颈 → 头 → 五官
├─ 肩 → 上臂 → 前臂 → 手
├─ 躯干 → 裙摆 / 胸部
└─ 头发根部 → 中段 → 发梢
```

- 主干使用持久姿态键形，负责转头、侧倾、俯仰和身体移动。
- 局部 warp 负责脸部体积、头发弯曲和裙摆形态。
- 旋转变形器负责有明确枢轴的部件；复杂区域使用连续网格变形。
- 剪贴与 Glue 等约束保持层间关系，避免内部补画和五官外溢。

### 8.3 多输入、分级物理链

- 追踪输入先经过映射和平滑，再进入原生参数。
- 头角、身体位置等持久分量保持姿态；头发、裙摆等瞬时分量产生延迟、过冲、衰减和回摆。
- 物理输出可以继续驱动下一级，例如身体 → 肩部 → 裙摆，头 → 前发 → 侧发/后发。
- 呼吸是一条外部自动输入，同时影响多个部位，但权重、延迟和幅度不同。
- 待机由参数、物理与必要动作共同形成，不用一条全局正弦曲线移动所有层。

### 8.4 运动降级

- 骨架或遮挡关系不可信时，限制对应轴的运动范围。
- 补画不足的区域不得获得超出余量的运动幅度。
- 导出前验证参数引用、变形器父子关系、枢轴和物理链路；失败不得标记为 `complex_motion_ready`。

### 8.5 M 轨验收

- 八姿态和连续复杂动作中无露底、反向拉扯、五官脱离或明显体积塌陷。
- 接缝采用配对顶点距离变化测量，不用位移差误判刚体运动。
- 物理轨迹检查主干保持、分级峰值时刻、衰减和回摆，而不是只检查参数发生变化。
- 官方 Core 与产品渲染器进行同参数对照，确认离线设计和实际导出行为一致。

## 9. S 轨：可插拔补画能力与自建风格模型

### 9.1 统一补画接口

输入：

- 原图及部件上下文；
- 必须保留的可见区域；
- 需要生成的遮挡区域；
- 部件语义、遮挡者、轮廓和运动方向；
- 周围颜色、线条及相邻纹理信息。

输出：完整 RGBA、生成区域、置信度和追溯信息。可见原图像素必须逐像素保留，禁止通过重绘整张角色来完成局部补画。

### 9.2 两阶段能力

**阶段 A：可验证的补画链路**

- 使用现有本地能力和 Telea、clone 等基础方法建立接口与测试。
- 基础方法只用于小区域和纹理延续，不得把窄缝填补冒充大块遮挡补画。
- 完整发束、裙片、尾巴或腿部等区域必须接入真正的 inpaint 能力。

**阶段 B：自建风格模型**

- 第一阶段聚焦赛璐璐与 chibi，不一开始追求通用画风。
- 优先采用可本地推理、可微调的结构；根据 6GB 显存实测决定训练、低显存微调或小型条件模块。
- 产品保留统一接口，不让用户绑定某个付费 API 或外部插件。
- 自建模型未达标前，必须如实记录实际算法或模型来源，不使用“自研”标签掩盖。
- 底座选择、数据规模和训练方法在独立训练方案中确定；开始前必须通过许可与资源实测闸门。

### 9.3 数据与许可闸门

- 训练数据只来自许可允许的网络素材或自生成图片。
- 每张样本记录来源、作者、许可、获取日期、允许用途和变换历史；许可不明则不进入训练集。
- DeepSeek 参考素材默认不进入训练集，不重新分发。
- 训练集和验证集按角色隔离，防止同一角色的近似图跨集造成虚假效果。

### 9.4 失败处理与验收

- 结构断裂、风格突变、重复纹理或可见区域改变时，自动拒绝该补画结果。
- 只重试失败区域，不改写其他已经合格的部分。
- 最终仍不可信时保留标记，并由 M 限制运动范围。
- 验收包括可见像素保护、大块补画盲测和实际运动测试，不能只看静止缩略图。
- 每个样本可追溯到输入、模型版本、许可记录和生成参数。
- 与基础方法做对照，证明模型升级确实改善大块补画，而非只增加耗时。

## 10. 统一测试与验收口径

### 10.1 测试协议

- 八姿态：静止、左转头、右转头、抬头、低头、侧倾、身体移动、复杂组合姿态。
- 连续动作：连续转头、身体侧倾与呼吸叠加，以及头发和裙摆的阶跃响应。
- 几何：真实遮挡层对、静止重合成、可见像素保护和补画余量。
- 运行时：官方 Core 加载、产品实际渲染、同参数行为对照。

### 10.2 四类质量门槛

1. **视觉与完整性**：接触表与盲测判断是否仍像同一个角色、运动是否自然；成片露底、部件反向运动、明显穿插或体积塌陷直接失败。
2. **几何**：测量真实遮挡层对的成片补画、遮挡核心和运动余量；静止重合成必须保持原形象。
3. **运动**：分别验收主干保持、部件分级延迟、transient 回摆、峰值、衰减和残差；不接受全层同步正弦运动。
4. **结构能力**：必须支持层级 warp/rotation、剪贴/蒙版/混合语义和物理级联，但不机械追求参考数量。

### 10.3 阈值与证据

- 实施开始时先对真实自动产物运行指标，记录当前基线和坏/好样本，再钉死自动闸门阈值。
- 指标必须指向被投诉的行为；像素变化量只用于证明动作确实发生，不作为质量分。
- 每次验收输出机器可读报告、姿态接触表和物理时间序列。
- 自动闸门必须配合变异测试，证明坏几何、坏装配和坏物理确实会被拦截。
- 只有全部实测通过，才声明达到目标；导出成功、文件存在或参数变化均不等于验收通过。

## 11. 实施顺序

### 阶段 0：固定基准与测试样本

- 固化八姿态、连续动作、物理轨迹和静止重合成工具。
- 建立许可清楚的自有测试角色集，保留当前产物作为对照组。
- 先跑真实产物校准阈值，再启用自动闸门。

### 阶段 1：修复 G 轨确定性缺陷

- 取消补画后再次擦除 alpha 的破坏环节。
- 保存遮挡、剪贴、蒙版和混合语义。
- 先证明静止形象不被分层过程破坏，再增加运动复杂度。

### 阶段 2：打通 S 轨大块补画

- 建立统一接口和可见像素保护测试。
- 基础方法覆盖小区域，inpaint 处理真实大块遮挡。
- 自建风格模型作为后续可替换升级，不阻塞几何与运动管线修正。

### 阶段 3：重建 M 轨运动结构

- 从共享主干场和头颈接缝开始，再扩展到四肢、头发和服装。
- 建立层级 warp/rotation、原生多输入物理与级联回摆。
- 已记录的头/颈、头/领接缝在这一阶段处理，不再单独堆补丁。

### 阶段 4：整体验收与产品化

- 完成自动导出、官方 Core 加载和产品实际渲染三层验证。
- 明确区分静态可用、受限运动和复杂运动可用。
- 通过真实角色验收后再决定版本构建；构建安装包不等于授权覆盖安装。

## 12. 最终发布门槛

- **形象**：静止重合成忠实于输入，盲测中不像换了一个角色。
- **完整**：八姿态和连续组合动作无成片露底、五官脱离、反向拉扯或明显体积塌陷。
- **自然**：主干姿态保持，头发与裙摆有分级延迟、衰减和回摆，不是全层同步正弦运动。
- **几何**：真实遮挡区域具有足够补画余量，可见原图未被改写。
- **原生**：导出的 moc3 能由官方 Core 加载，产品渲染器与官方 Core 在同参数下的求值行为一致。
- **可信**：失败与降级明确可见，测试数据、参考公皮和许可不明素材不混入发布包。
- **回归**：既有自动化测试保持通过，新门槛能被变异测试证明确实会拦截坏产物。

## 13. 参考素材使用边界

DeepSeek 公皮用于结构研究、统一协议和视觉/运动对照。其使用规范允许学习、建模练习和署名展示，但不允许擅自重新分发原始 PSD 或完整模型、出售或冒认作者；商业打包或付费商品用途需先联系作者。

因此：

- 不将参考原始资产并入产品或发布包。
- 不默认将其用于训练。
- 如公开衍生展示，署名“原画及拆分：神宫凉子；Live2D 建模：霓虹猫_NeonNeko”。
- 自动产物训练与发布使用独立、许可清楚的数据集。
