# 真实原生模型验收进展

## 实测结果

测试资源来自 Live2D 官方 CubismWebSamples 的 Haru 样例，仅作为本地测试输入，未打包分发。
来源：https://github.com/Live2D/CubismWebSamples/tree/develop/Samples/Resources/Haru

真实运行日志确认 Cubism Core 05.01.0000；Python 包的 v3 模块名不表示 Core 版本为 3。

| 参数 | 有效像素 | 变化像素 | 静止对照漂移 | 复位误差 |
|---|---:|---:|---:|---:|
| 转头 ParamAngleX | 30502 | 2653 | 0 | 0 |
| 张嘴 ParamMouthOpenY | 30652 | 94 | 0 | 0 |
| 左眼 ParamEyeLOpen | 30652 | 127 | 0 | 0 |

通过条件：存在有效 alpha 像素，参数两端产生显著像素变化，静止对照保持稳定，复位后画面恢复。禁用自动眨眼与呼吸，并冻结更新时钟，避免自动动画干扰。

结果仅证明该样例在本机 OpenGL 环境中的像素与参数驱动有效；不是所有模型、所有平台或 VTube Studio 的通用认证。

## 桌宠

新增 Windows 原生 OpenGL 桌宠窗口，复用桌宠事件机制，支持无边框、置顶与拖动。官方样例实际运行 60 帧后正常退出。

当前透明方式是 Windows 色键透明，不是逐像素 alpha。保留洋红背景色，抗锯齿轮廓可能有边缘杂色。尚未完成桌面合成画面视觉验收，也尚未替换所有旧软件桌宠入口。

## 服务端

部署端点现在要求已有真实模型目录，并实时启动独立 Python 验收进程，不接受客户端声明的验收结果。限制为配置输出根目录内唯一清单，一次仅运行一个 GPU 验收，设有超时。失败拒绝，成功返回可启动标记和参数数组；不会把未启动的进程标成已部署。

当前无可用 Go 命令，服务端修改尚未编译和 HTTP 联调。服务运行账户需要交互桌面、GPU 上下文以及配置正确的 Python 环境。
