# Cubism 参数模板

## 基础参数

| 参数名 | 说明 | 范围 |
|--------|------|------|
| ParamAngleX | 左右转头 | -30 ~ 30 |
| ParamAngleY | 上下点头 | -30 ~ 30 |
| ParamAngleZ | 左右歪头 | -30 ~ 30 |
| ParamEyeLOpen | 左眼开合 | 0 ~ 1 |
| ParamEyeROpen | 右眼开合 | 0 ~ 1 |
| ParamMouthOpenY | 嘴巴开合 | 0 ~ 1 |
| ParamMouthForm | 嘴型变化 | 0 ~ 1 |
| ParamBodyX | 身体左右移动 | -10 ~ 10 |
| ParamBodyY | 身体上下移动 | -10 ~ 10 |

## 扩展参数

| 参数名 | 说明 |
|--------|------|
| ParamHairFront | 前发摆动 |
| ParamHairBack | 后发摆动 |
| ParamEyeBlink | 眨眼 |
| ParamBreath | 呼吸 |
